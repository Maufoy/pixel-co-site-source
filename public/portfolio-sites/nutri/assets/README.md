# Assets — substituir placeholders

## Imagens necessárias

### 1. Foto do Raphael
- **Arquivo:** `assets/raphael.jpg`
- **Proporção ideal:** 4:5 (vertical), mínimo 800×1000px
- **Mood:** fundo escuro/neutro, postura confiante, vestimenta esportiva ou camisa social
- **Onde aparece:** hero (topo) + seção "Sobre"

### 2. Depoimentos
- **Arquivos:** `assets/depoimentos/dep-01.jpg` até `dep-06.jpg`
- **Proporção ideal:** 4:3 (horizontal), mínimo 800×600px
- **Conteúdo:** prints/screenshots de avaliações reais do Doctoralia e Google
- **Dica:** padronizar fundo (todos com a mesma cor) ou já editar como cards

## Otimização

Antes de subir, otimizar com:
- **Squoosh** (https://squoosh.app) — converter para `.webp` ou `.jpg` qualidade 80
- **TinyPNG** (https://tinypng.com) — alternativa
- **Tamanho alvo:** < 200 KB por imagem

## Substituição

Apenas troque os arquivos pelos nomes acima. Os placeholders no design somem automaticamente assim que a imagem real for carregada.
